## v0.10 の変更点

## v0.4の設計変更（引き続き利用可能）

v0.3では、SVGを115%に拡大した後、SVG内部の15%フェードの一部分が切り落とされ、ページ左右端で線が突然終わっていました。また、レイヤーの移動・回転・縮小によって一部の線の**数学的な終点そのもの**が画面内に入っていました。SVGの高さ方向の境界でも、三角形メッシュなどが横一線で突然終わっていました。

v0.4では処理を次のように分割しています。

1. **可視領域から逆算**: SVGキャンバスの4隅をレイヤーの移動・回転・スケールの逆変換で元の座標へ戻します。波線、曲線グリッド、扇状曲線、メッシュ等はその範囲の**外側まで**生成します。
2. **線の種類に応じて終点を解消**: 扇状曲線は可視範囲を横断する式へ変更。円弧は閉じた楕円で描きます。メッシュや六角形は可視領域の外までセルを追加します。
3. **左右のフェードはCSS側**: 擬似要素（`::before` と `::after`）に、**実際のページ幅**を基準としたmaskを適用します。SVGを115%にしてもフェード後の画面端が切れません。
4. **上下のフェードはSVG側**: 上部装飾は画像の下辺、下部装飾は上辺を滑らかに薄くし、模様の範囲に水平な切断線が現れないようにします。新しい「模様の上下境界をなめらかに消す」スライダーで調節できます。

通常SVGモードの従来アルゴリズムは変更していません。新方式は**Web背景モード**に適用されます。

## UIでの使い方

1. Web背景モードでプリセットを選択します。
2. 上部または下部のタブで配置を選び、必要ならレイヤー位置を調整します。
3. ページ左右端のフェードと、上下境界のフェードを調整します（初期値は左右15%、上下28%）。
4. **画面幅に合わせる(100%)**か**画面より広く(115%)**を使用すると、SVG画像の端がページ内に露出しにくくなります。
5. ZIPで `top.svg`, `bottom.svg`, `example.css`, `theme.json`, `preview.html` を保存します。

> 固定幅や100%未満で表示する場合は、意図的に画像の端がページ中央に現れることがあります。このようなローカル配置は、画面幅全面を覆う「線が続く背景」とは別の用途です。フェードや配置の調整で対処してください。

### Reactへの組み込み

`top.svg` と `bottom.svg` を `public/themes/` に置き、**`example.css` の `.page-background` / `::before` / `::after` の3ルールすべて**を採用します。v0.3の単一backgroundプロパティとはCSS構造が異なります。既存CSSの単なる追記ではなく置換してください。

CSSの擬似要素は`position:absolute;z-index:-1;`で装飾をUIの背面にし、親は`isolation:isolate`でスタッキングコンテキストを分離しています。親に独自の疑似要素を使っている場合はCSSを統合する必要があります。

## v0.6: コピーしてから少しずつ変える

Web背景モード・通常SVGモードの両方に次の操作を追加しました。

- **完全複製**: 選んだレイヤーの直上に、まったく同じ設定のレイヤーを作ります。元レイヤーは変化しません。
- **少しずらして複製**: 直上に、左右 +8%、回転 +5°、線の濃さ 80% のコピーを作ります。模様の種類・線の数・ランダム値 (seed) は維持します。
- **レイヤー間コピー**: 「1 → 2 にコピー」など、既存のレイヤーを選んで上書きコピーします。コピー先の従来設定はなくなるので注意してください。
- **矢印・回転の微調整**: 移動 1/2/3/5/10%、回転 1/2/3/5/10°をボタンで変更します。スライダーで細かな値も変更できます。
- **差分確認**: レイヤー1と2の左右差・上下差・回転差・拡大差と、模様を決定する条件が一致しているかを表示できます。
- **Web背景モードの取り消し**: 直前のレイヤー追加・複製・上書き・移動・削除・順序変更を元に戻します。（スライダーによる通常編集の取り消しではありません。）

### おすすめの作業例

1. 上部SVGの「流れる波線」を1つ作り、線の数・色・フェードを調整します。
2. レイヤーの「少しずらして複製」を押します。複製先が自動的に展開します。
3. 複製側で「矢印と角度で微調整」を押し、1〜3%ずつ左右へずらしたり、2〜5°ずつ回転させます。
4. 「ほかのレイヤーとの差分を見る」で元レイヤーとの差を確認します。
5. 色や合成モード (`screen` など) を少し変えると、線の交差部分に立体感が生まれます。

### 重要: 三角形メッシュとドットの生成処理変更

従来のWeb背景モードは、表示範囲を広げるたびに乱数を順番に引き直していたため、同じ seed でも移動・回転時に格子そのものが変わる問題がありました。v0.6は各格子座標から安定した乱数を求める方式に変更しています。同じ模様のコピーが本当に同じ形で重なります。線切れ対策で加えていた画面外への描画も維持しています。

この変更により、**以前のv0.5で書き出した三角形メッシュ・ドットと、v0.6で再生成した同じseedの見た目は異なる場合があります**。新規テーマはv0.6の結果に統一することをおすすめします。極端な縮小で生成上限に達したときは、メッシュの解像度が変わる場合があります。

既存のuvプロジェクトでは `src/svg_pattern_studio/` を上書きしてください。`layer_tools.py` が新規追加ファイルなので、既存ファイルの上書きだけではなく、ディレクトリ全体をコピーしてください。依存ライブラリの追加はありません。
